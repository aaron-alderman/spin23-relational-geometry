# Frontier wave 3: operational closure, provenance and UV correlation

**Opened:** 18 October 2026  
**Parent:** [Wave 2 synthesis](frontier_wave2_03_synthesis_three_gates_end_at_external_data.md)

Wave 2 showed that the existing structure fixes admissible families but not the physical point inside them. Wave 3 asks whether measurement, the full finite representation, or a minimal ultraviolet completion can supply that point without disguising new free data.

## W3-A — operational closure

Find the smallest observable set that determines the calibrated electron-face products and discriminates the two source rays. The ideal rank theorem and realistic sensitivity must be reported separately. A rate-only design must state every surviving sign ambiguity; a signed determination requires an interference observable.

## W3-B — finite-geometry provenance

Act on the \(\mathbb{CP}^2\) safe-projector family with every already established datum: gauge commutant, real structure, grading, anomaly-free TRO, electron anchor and represented Dirac/Yukawa support. Determine the exact residual orbit. A unique projector counts only if no new coefficient or basis choice was inserted.

## W3-C — UV correlation

Construct or exclude the smallest anomaly-completed model correlating the source ray with the safe/danger projector. The audit includes allowed counterterms and heavy-threshold regeneration. A fitted correlation is a benchmark; a symmetry-protected correlation is a theoretical advance.

## Decision rule

The programme advances beyond underdetermination only if one route fixes a physical point and another independent route can test it. Otherwise the correct endpoint is a calibrated phenomenological benchmark plus a precise provenance no-go.
