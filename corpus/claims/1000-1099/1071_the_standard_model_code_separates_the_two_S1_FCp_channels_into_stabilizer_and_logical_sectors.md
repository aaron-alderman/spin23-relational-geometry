## 2. Code conventions

Write the sixteen \(Spin(10)\) chiral-spinor weights as

\[
q(f)\in\{\pm1\}^5,
\qquad
\prod_{a=1}^5q_a(f)=+1,
\]

with

\[
q(\nu^c)=(1,1,1,1,1).
\]

After puncturing \(\nu^c\), let \(W_0\) be the four-dimensional stabilizer-row space generated by the \(SU(5)\) Cartan differences

\[
h_a=\frac{q_a-q_{a+1}}2,
\qquad a=1,\ldots,4.
\]

Add one charge row \(g\) satisfying \(g(\nu^c)=1\); the first sign coordinate \(q_1\) is sufficient. Then

\[
W=\langle W_0,g\rangle.
\]

For a punctured support vector \(v\):

- \(v\in W_0^\perp\) means that the corresponding \(Z(v)\) commutes with all \(X\)-stabilizers;
- \(g\cdot v=0\) places it in \(W^\perp\), the logical-neutral \(Z\)-stabilizer sector;
- \(g\cdot v\ne0\) makes it a logical \(Z\) operation.

This distinction is valid over every odd prime. The binary code uses occupation-bit rows instead, and the same classification survives: occupation parity gives the stabilizer syndrome, while overlap with the punctured all-one logical row is Hamming-weight parity.

## 3. The \(u^ce^c\) channel is logical-neutral

For each colour \(i=1,2,3\), \(\mathcal Q_{ue}\) has two weak components,

\[
u_i e\,u_i^ce^c,
\qquad
-d_i\nu\,u_i^ce^c.
\]

Their overall relative minus sign is a weak-contraction amplitude and does not change which fields occur in a charge relation. The five-sign weights obey

\[
q(u_i)+q(e)+q(u_i^c)+q(e^c)=0,
\]

\[
q(d_i)+q(\nu)+q(u_i^c)+q(e^c)=0.
\]

All four fields remain after the \(\nu^c\) puncture. Hence each support is orthogonal to every one of the five charge rows, including the logical row:

\[
h_a\cdot v=0,
\qquad
g\cdot v=0.
\]

Thus all six component supports lie in \(W^\perp\). In the binary code each has even occupation syndrome and even weight four, giving the same result.

This does **not** mean that a single displayed colour component is by itself a complete non-Abelian gauge invariant. The contracted sum is the physical operator. The code statement concerns the exact charge support of each component.

## 4. The \(d^c\nu^c\) channel is a minimum logical

For each colour \(i\), \(\mathcal Q_{\nu d}\) contains

\[
u_i e\,d_i^c\nu^c,
\qquad
-d_i\nu\,d_i^c\nu^c.
\]

Again the complete four-field weights sum to zero:

\[
q(u_i)+q(e)+q(d_i^c)+q(\nu^c)=0,
\]

\[
q(d_i)+q(\nu)+q(d_i^c)+q(\nu^c)=0.
\]

After deleting the puncture coordinate, however, the remaining three physical fields obey

\[
q(u_i)+q(e)+q(d_i^c)=-q(\nu^c),
\]

\[
q(d_i)+q(\nu)+q(d_i^c)=-q(\nu^c).
\]

Every stabilizer row is neutral on \(\nu^c\), so both triples remain in \(W_0^\perp\). But the logical row gives

\[
g\cdot v=-1
\]

over the integers and every odd prime. In the binary construction the three-field support has odd weight. These are therefore nontrivial logical-\(Z\) operations of minimum weight three.

The first set is precisely the three **scalar charged-current** logicals,

\[
\nu^c=-u_i-d_i^c-e,
\]

and the second set is the three **down-type Dirac** logicals,

\[
\nu^c=-d_i-d_i^c-\nu.
\]

This independently picks out six of the paper's 25 minimum logical supports.

## 5. The asymmetry is created by the puncture

Before puncturing, every component above is simply a four-spinor zero-sum relation in the complete \(\mathbf{16}\). The stabilizer/logical distinction appears only because one channel contains \(\nu^c\) and the other does not.

Therefore there are three mathematically distinct places where a relation between the two channels might live:

1. **Unpunctured symmetry.** A transformation of the full sixteen-state shell may relate the quartets, but it need not descend to a symmetry fixing the \(\nu^c\) puncture.
2. **Logical-changing operation.** A transformation of the punctured code may exchange the channels only if it also changes the logical sector rather than acting trivially on the encoded qudit.
3. **Dynamical matching.** Mediator masses, couplings, a Ward identity, or a vacuum condition may impose a coefficient relation without it being a code automorphism.

This is the useful uncomfortable branch: the desired \(F_Cp\) equality may be ultraviolet, logical, or dynamical, but it is not a symmetry of the puncture-fixed charge code as currently typed.
