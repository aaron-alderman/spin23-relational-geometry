## 1. Missing finite symplectic generators

The finite \(Sp(4,\mathbb F_3)\) branch needs two qualitatively different operations:

- a change of polarization, exchanging logical \(X\) and \(Z\);
- a shear, sending \(Z\mapsto Z+KX\) for a symmetric \(2\times2\) matrix \(K\).

The most direct physical candidates are sitewise qutrit Fourier and phase Clifford gates. Both can be classified exactly for the two-puncture CSS code.

## 2. No nontrivial partial Fourier mask

At one physical coordinate the Fourier Clifford acts symplectically as

\[
(x_i,z_i)\longmapsto(-z_i,x_i).
\]

The certificate exhausts all

\[
2^{14}=16384
\]

subsets of physical qutrits on which this transformation could be applied, testing whether the resulting twelve-dimensional stabilizer space equals the original one.

Only the empty subset works:

\[
\boxed{
\text{no nontrivial tensor product of identity/Fourier gates preserves the code.}
}

The full Fourier transform also fails because it would interchange an \(X\)-stabilizer space of dimension three with a \(Z\)-stabilizer space of dimension nine.

## 3. Diagonal Clifford profiles

A sitewise phase Clifford with exponent profile

\[
c=(c_1,\dots,c_{14})\in\mathbb F_3^{14}
\]

acts by

\[
(x,z)\longmapsto(x,z+D_cx),
\qquad
D_c=\operatorname{diag}(c_1,\dots,c_{14}).
\]

It preserves the CSS stabilizer precisely when

\[
h\cdot(D_ca)=0
\]

for every punctured charge word \(h\in H\) and every \(X\)-stabilizer word \(a\in A\).

Solving these constraints gives a five-dimensional profile space with

\[
3^5=243
\]

elements.

The constraint solution is not an unrelated five-dimensional subspace. The certificate verifies

This is a source-derived result: the same lattice that encodes anomaly cancellation supplies every code-preserving diagonal Clifford profile.

## 5. Logical action: diagonal shears only

For logical \(X\) representatives \(\ell_i\), the induced shear is

\[
K_{ij}=\ell_i\cdot D_c\ell_j.
\]

Across all 243 allowed profiles, the image consists of exactly nine matrices:

\[
K=
\begin{pmatrix}
a&0\\
0&b
\end{pmatrix},
\qquad a,b\in\mathbb F_3.
\]

The off-diagonal entries always vanish. The kernel has dimension three, exactly the dimension of the \(X\)-stabilizer parameter space, leaving the two puncture evaluations as the two independent logical phase parameters.

Thus

\[
\boxed{
\text{charge-word phase profiles give two independent one-logical shears but no relational shear.}
}

The profile

The distinction between Clifford hierarchy levels is essential.

## 8. Scope of the no-go

The exhaustive Fourier result covers tensor products in which each site receives either identity or the standard Fourier gate. The shear classification covers arbitrary site-dependent diagonal Clifford profiles.

It does not exhaust every tensor product of arbitrary one-qutrit Clifford gates combining Fourier and phase factors in different local orders. However, the independent logical-weight theorem already proves that no support-preserving local-Clifford-permutation group can realize the entire \(Sp(4,\mathbb F_3)\).
