# The ordered-frame return equation is exact, but a frame-only equivariant response is the identity, not a selector

## Main result

Promoting the return map from one projector to a complete ordered Jordan frame is mathematically straightforward. It also exposes the next no-go immediately.

Let

\[
\mathfrak F=(F_1,F_2,F_3),
\qquad
F_iF_j=\delta_{ij}F_i,
\qquad
\sum_iF_i=I.
\]

For an effective action \(\Gamma[\mathfrak F]\), define the three Hermitian response derivatives

\[
R_j[\mathfrak F]=\frac{\delta\Gamma}{\delta F_j}.
\]

Constrained variation on the flag orbit gives the exact stationarity equation

\[
\boxed{
\sum_{j=1}^3[F_j,R_j]=0.
}
\]

A single nondegenerate response operator can package this as a spectral-frame return equation. But if that response is \(U(3)\)-equivariant and its only family datum is the frame itself, then it must have the form

\[
\boxed{
\mathcal R[\mathfrak F]=r_1F_1+r_2F_2+r_3F_3
}

with constant coefficients. Its spectral frame is therefore \(\mathfrak F\) for every input frame. The return map is the identity on the whole flag manifold, not a selector.

Thus completing the projector to a frame fixes the *type* of missing object but does not generate its relative orientation.

## 1. Constrained variation of an ordered frame

Every infinitesimal variation preserving orthogonality, rank and completeness is induced by a common anti-Hermitian generator \(K\):

\[
\delta F_j=[K,F_j].
\]

Then

\[
\begin{aligned}
\delta\Gamma
&=\sum_j\operatorname{Tr}(R_j\delta F_j)\\
&=\sum_j\operatorname{Tr}(R_j[K,F_j])\\
&=\operatorname{Tr}\!\left(K\sum_j[F_j,R_j]\right).
\end{aligned}
\]

Since \(K\) is arbitrary modulo the diagonal stabilizer, stationarity is equivalent to

\[
\sum_j[F_j,R_j]=0.
\]

This collective equation is weaker than demanding each commutator vanish separately. The distinction matters whenever the three projector derivatives are not generated by one common response.

## 2. Packaging the frame with a labelled carrier

Choose three fixed distinct real labels

\[
c_1<c_2<c_3

\]

and form the carrier

\[
C_{\mathfrak F}=\sum_jc_jF_j.
\]

The ordered frame is exactly the spectral frame of \(C_{\mathfrak F}\). If a Hermitian response \(\mathcal R[\mathfrak F]\) has a simple ordered spectrum, the natural return equation is

\[
\boxed{
F_j=\Pi_j\bigl(\mathcal R[\mathfrak F]\bigr),
\qquad j=1,2,3.
}
\]

Equivalently,

\[
[C_{\mathfrak F},\mathcal R[\mathfrak F]]=0

\]

together with an eigenvalue-ordering rule. The commutator alone permits permutations; the ordering rule fixes which eigenspace is called first, second and third.

## 3. The frame-only equivariance theorem

Assume

\[
\mathcal R[g\mathfrak Fg^\dagger]
=g\mathcal R[\mathfrak F]g^\dagger

\]

for every \(g\in U(3)\), and assume no family datum other than \(\mathfrak F\) enters.

At the reference diagonal frame \(\mathfrak F_0\), the stabilizer is the diagonal torus \(U(1)^3\). Equivariance forces \(\mathcal R[\mathfrak F_0]\) to commute with that torus, so it is diagonal:

\[
\mathcal R[\mathfrak F_0]=\sum_jr_jF_j^{(0)}.

\]

The ordered flag manifold is a transitive \(U(3)\)-orbit. Therefore the \(r_j\) cannot vary with the frame; any invariant scalar function on that orbit is constant. Conjugating the reference result gives

\[
\mathcal R[\mathfrak F]=\sum_jr_jF_j

\]

for every frame.

There are only two outcomes:

1. if the \(r_j\) are distinct, every frame returns itself;
2. if some \(r_j\) coincide, the response forgets part of the frame and the return is even less determinate.

Hence

\[
\boxed{
\text{frame-only equivariant return gives identity or degeneracy, never orientation selection.}
}

## 4. The scientifically relevant object is a relative double frame

Absolute common orientation is a basis convention. Physical flavour data live in the relative geometry of two frames, for example

\[
\mathfrak E=(E_i)\quad\text{from }A,
\qquad
\mathfrak F=(F_j)\quad\text{from }B.
\]

A simultaneous rotation

\[
(\mathfrak E,\mathfrak F)mapsto
(g\mathfrak Eg^\dagger,g\mathfrak Fg^\dagger)

\]

changes no physics. The selector must act on their relative double-coset geometry, equivalently on the four overlap moments of document 1212.

The correct return problem is therefore not

\[
\mathfrak F\mapsto\mathfrak F,

\]

but

\[
\boxed{
(\mathfrak E,\mathfrak F)
\longmapsto
\bigl(\operatorname{SpecFrame}\mathcal R_A[\mathfrak E,\mathfrak F],
\operatorname{SpecFrame}\mathcal R_B[\mathfrak E,\mathfrak F]\bigr)
}


modulo common conjugation.

## 5. What degree sixteen actually supplies

The potential

\[
V_{16}=\sum_{p,q=1}^2\lambda_{pq}
\bigl(\operatorname{Tr}(A^pB^q)-y_{pq}^*\bigr)^2

\]

selects a relative double-frame overlap. It evades the frame-only theorem because both \(A\) and \(B\) are present.

But the target \(y^*\) remains external. Equivariance permits such constants; it does not determine them. The closure gap has therefore narrowed to a coefficient problem:

\[
\boxed{
\text{What internal dynamics determines the four invariant target moments and their weights?}
}

This is better posed than asking what selects an absolute family direction, because the latter is partly a basis artifact.

## 6. Next stop-everything test

Candidate derivations of \(y^*\) should now be tested against three requirements:

1. **integrability:** the proposed response must arise as the derivative of an effective action;
2. **relative covariance:** it may depend on both frames but not on an unphysical absolute basis;
3. **noncircularity:** the target moments cannot simply be inserted into the response under another name.

The most direct next calculation is to integrate out the declared charge-three cross-Peirce link and ask whether its determinant or loop effective action generates a nontrivial function of all four double-frame moments with fixed coefficient ratios.
