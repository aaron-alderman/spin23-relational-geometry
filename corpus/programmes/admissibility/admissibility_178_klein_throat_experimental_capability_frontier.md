## Purpose

The next task is not to seek one spectacular effect. It is to determine which
parts of the joined model can be realized, controlled and distinguished:

\[
\mathcal C=
\mathcal T\times\mathcal G\times\mathcal D\times\mathcal V\times\mathcal O,
\]

where \(\mathcal T\) is return topology, \(\mathcal G\) geometry,
\(\mathcal D\) dynamical regime, \(\mathcal V\) constitutive law and
\(\mathcal O\) observation channel. A point in this space is a declared
experiment, not merely a shape.

## The capability ladder

| level | admitted capability | decisive record | strongest claim available |
|---|---|---|---|
| C0 | numerical double cover | exact deck residual | equations respect the quotient |
| C1 | programmable linear quotient | coherent one/two-lap transfer | sewing is physically implemented |
| C2 | calibrated modal emulator | nullity and positive spectrum | topology/operator hypotheses separate |
| C3 | tunable metric weights | gap and mixing versus throat strength | geometry controls the predicted blocks |
| C4 | controlled nonlinearity | allowed daughters and forbidden leakage | selected mode algebra survives dynamics |
| C5 | material thin layer or interface | vector ring-down and work ledger | a constitutive physical system selects an operator |

C0 has already closed. C1--C4 can be approached with a programmable circuit,
acoustic lattice, mechanical lattice or real-time control system. C5 requires
a material platform and its own stress or thin-layer derivation.

## Frozen order of experiments

1. **Calibrate local components without quotient sewing.** Determine the
   complex transfer functions, loss, detector phase and uncertainty.
2. **Close matched reflection and rotation returns.** Hold component count,
   local weights and ports fixed; change only the sewing permutation.
3. **Measure signed one- and two-lap return.** Establish \(-1,+1\) for the
   reflected transverse channel and \(+1,+1\) for the rotation control.
4. **Recover the full linear spectrum.** Estimate kernel dimension, first
   positive gap and mode shapes from the complex transfer matrix.
5. **Sweep the throat parameter.** Preserve the declared global capacity and
   test symmetry-compatible mixing and \(O(\varepsilon^2)\) lifted gaps.
6. **Introduce weak nonlinearity.** Measure allowed daughters, closed-loop
   phases, invariant budgets and forbidden-sector leakage.
7. **Add declared defects.** Map robustness against loss imbalance, imperfect
   sewing, detuning, missing links and detector phase error.
8. **Only then choose a material realization.** Derive its constitutive
   operator rather than assigning Hodge, Bochner or deformation viscosity by
   resemblance.

Each stage freezes the previous calibration. Refitting earlier parameters to
make a later stage pass destroys the evidential chain.

## Minimal joined record

No single scalar is adequate. The minimum record is

\[
R=(r_1,r_2,n_0,\lambda_1^+,p_{\varepsilon},
   \mathcal L_{\mathrm{forbidden}},\Delta E),
\]

with signed one/two-lap returns \(r_1,r_2\), kernel dimension \(n_0\), first
positive gap \(\lambda_1^+\), fitted throat exponent
\(p_{\varepsilon}\), forbidden-sector leakage and the closed energy/work
residual. Total power or one decay constant cannot substitute for this tuple.

## Matched controls

| target | required control | why it is required |
|---|---|---|
| reflected return | equal-size rotation return | separates topology from component count |
| throat weighting | sign-reversed and zero throat | separates curvature scaling from static disorder |
| kernel plateau | extended observation and detector floor | separates a null mode from a slow decay |
| nonlinear daughter | phase-scrambled and forbidden-sector probes | separates triad closure from broadband distortion |
| material viscosity | all three operator fits | prevents selecting the preferred law by assertion |

The rotation control is not an optional baseline. It is a second face of the
same experiment.

## Decision tree

- If the signed return fails, stop before spectral interpretation: the
  quotient has not been implemented or observed.
- If signed return passes but shared calibration modes fail, repair the local
  model before attributing differential modes to topology.
- If spectra pass but the throat exponent is not near two, test frozen defects
  and weight normalization before changing the geometry model.
- If linear gates pass but nonlinear leakage rises, report the amplitude at
  which the selected algebra ceases to close.
- If an emulator passes C1--C4, it demonstrates the relational mechanism but
  does not yet establish a Newtonian material surface.
- If a material system passes C5, compare the inferred operator with its
  independently derived stress law.

## Negative results that move the frontier

A null result is useful when it closes a capability region:

- a power-only detector cannot distinguish the matched return topologies;
- a phase-calibrated detector that still sees no sign reversal excludes the
  intended sewing within its error bound;
- a lifted plateau at longer time excludes an exact kernel;
- a linear throat gap identifies a first-order defect or a different model;
- immediate forbidden-sector leakage bounds the usable nonlinear regime;
- failure of the work ledger identifies hidden active ports or unmeasured
  dissipation.
