# Ordered defect commutator and false-topology control

**Date:** 30 October 2026

**Status:** ordinary linear order effect derived and dependency-free gate passed; measured topology-dependent excess open

**Parents:** [defect capability map](admissibility_181_throat_nonlinearity_and_defect_capability_map.md), [experimental literature collision](admissibility_183_experimental_literature_collision_and_platform_reprioritization.md)

## Why this control is necessary

Nonorientable mechanical metamaterials motivate applying two localized
perturbations in opposite orders. A different final response can store useful
path information, but noncommutativity is not by itself a topological
signature. Ordinary linear generators already produce it.

For short perturbations generated by \(A\) and \(B\),

\[
e^{\tau B}e^{\tau A}-e^{\tau A}e^{\tau B}
=\tau^2[B,A]+O(\tau^3).
\]

The topology claim must therefore concern an excess, selection rule or robust
transport of this response after the local generator commutator is calibrated.

## Executable baseline

The [dependency-free verifier](../../../verification/admissibility/verify_ordered_defect_commutator_control.mjs)
uses a rotation generator and a stretch generator,

\[
A=\begin{pmatrix}0&1\\-1&0\end{pmatrix},
\qquad
B=\begin{pmatrix}1&0\\0&-1\end{pmatrix}.
\]

Across \(10^{-3}\leq\tau\leq10^{-1}\), the first five durations give an
order-difference exponent of \(1.99999\). At the smallest duration the exact
response differs from \(\tau^2[B,A]\) by less than \(7\times10^{-7}\) relative.
A commuting rotation-generator control gives zero order residual at machine
precision.

## Physical protocol

1. Identify the unperturbed state-space generator.
2. Apply localized perturbation \(A\) for duration \(\tau\), then \(B\).
3. Reset to the same state and apply \(B\), then \(A\).
4. Repeat over duration and amplitude, including the commuting control.
5. Infer the individual perturbed generators from single-defect runs.
6. Predict \(\tau^2[B,A]\) without fitting the paired runs.
7. Compare reflection and rotation sewings using the same defects and ports.
8. Repeat with long reset times, reversed drive polarity and passive hardware
   to bound hysteresis, latency and heating.

Define the unexplained record

\[
R_{\mathrm{excess}}(\tau)=
R(B\circ A)-R(A\circ B)-\tau^2\widehat{[B,A]}.
\]

Only a reproducible excess with a declared sewing dependence moves the
nonorientable-memory claim.

## Outcome map

| result | interpretation |
|---|---|
| quadratic difference predicted by \([B,A]\) | ordinary sequential linear dynamics |
| nonzero commuting-control difference | memory, latency, heating or reset failure |
| excess common to both sewings | unmodelled local dynamics |
| excess only under reflected sewing | topology-dependent candidate requiring replication |
| order effect lost in power but present coherently | detector erases the signed record |
| persistent excess as \(\tau\to0\) | timing offset, impulse or singular switching before topology |

## Frontier consequence

The ordered-defect experiment is worthwhile, but it sits after C2 calibration.
Without identified local generators it cannot distinguish a global relational
memory from the elementary fact that matrices need not commute. This closes
the last apparatus-independent branch opened by the literature comparison.
