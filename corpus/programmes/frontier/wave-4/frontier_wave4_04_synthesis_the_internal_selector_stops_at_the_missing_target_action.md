# Frontier wave 4 synthesis: the internal selector stops at the missing target action

**Date:** 18 October 2026  
**Parent:** [Wave 4 programme](frontier_wave4_00_cross_carrier_intertwiner_programme.md)  
**Status:** all three established-provenance routes reach scoped no-go or explicit indeterminacy; internal selector programme stops at this rung

## Verdict

Wave 4 attempted to construct the non-scalar cross-carrier operator isolated in wave 3 without importing the exceptional (QQ) row. It attacked the problem from three independent directions:

1. Furey/Jordan representation theory;
2. the complete exceptional action and its radiative response;
3. Peirce, ribbon, code/lattice and (Spin(2,3)) orientation transport.

None produces a canonical, protected, non-scalar operator on the mediator-copy space

\[
W_{\rm mediator}cong\mathbb C^3.
\]

The common obstruction is now exact:

\[
\boxed{
\text{the established source structures do not derive a nontrivial target action }
\rho_W:G\to U(W_{\rm mediator}).
}
\]

Without that action, a cross-map either vanishes, chooses an arbitrary line in (\mathbb{CP}^2), or produces a model-dependent kernel whose eigenvectors rotate under allowed parameters and counterterms.

## 1. Furey/Jordan Hom classification

Gauge representation matching alone suggests a map from the Furey matter sector to the scalar leptoquark copies. Physical grading kills it:

\[
\operatorname{Hom}_{G_{\rm SM},\gamma}
(M_{\rm matter},W_{\rm scalar})=0.
\]

The optional bosonic Furey (S_1) fluctuation has the correct type and yields

\[
\operatorname{Hom}_{G_{\rm SM},\gamma}
(S_1,S_1\otimes\mathbb C^3)\cong\mathbb C^3.
\]

A strict TRO morphism fixes the norm of the coefficient vector (y), but not its direction:

\[
\|y\|=1,
\qquad [y]\in\mathbb{CP}^2.
\]

The induced rank-one Gram (yy^\dagger) is non-scalar only after a point of the unresolved projector family has been chosen. Naturality under the surviving (U(3)) target commutant gives

\[
W^{U(3)}=0,
\qquad
\operatorname{Herm}(W)^{U(3)}=\mathbb R I_3.
\]

Thus the canonical linear map is zero and the canonical positive Gram is scalar. Furey incidence normalizes a possible arrow but does not orient it among the unified copies.

## 2. Exceptional action and self-energy classification

The complete triplet couplings do generate non-scalar spectral kernels at chosen action points. For equal one-family Yukawa coefficients and equal channel weights,

\[
K_1=
\begin{pmatrix}
9&-3&5\\
-3&5&-3\\
5&-3&5
\end{pmatrix}.
\]

But neither the (QQ) line nor the previously identified safe vector is an eigenline. More decisively, another admissible point with the same nonzero coupling support yields

\[
K_2=
\begin{pmatrix}
36&-6&10\\
-6&5&-3\\
10&-3&5
\end{pmatrix},
\]

and

\[
[K_1,K_2]
=
\begin{pmatrix}
0&84&-124\\
-84&0&0\\
124&0&0
\end{pmatrix}
\ne0.
\]

The action class therefore has no parameter-independent eigenbasis. Symmetry-allowed mass mixing and finite counterterms rotate any selected line. Finite-Dirac support alone also fails: matrices with identical support can have noncommuting (D_F^\dagger D_F).

A fully specified renormalized model can predict pole mixing. That is a conditional model prediction, not a canonical selector derived from representation content. The same exceptional action remains compatible with both incidence rays because it contains no typed map from the seven-current source space to (W).

## 3. Topology and (Spin(2,3)) classification

The Peirce carrier and three-label ribbon/permutation carrier are genuine three-dimensional modules of type

\[
1\oplus2.
\]

With the established trivial action on (W), every equivariant map factors through the source singlet and has rank at most one. Its normalized image is again an arbitrary point of (\mathbb{CP}^2).

If the same (1\oplus2) action is first assigned to (W), full-rank intertwiners become possible, but the assignment itself chooses a singlet line and doublet plane. Equivariance leaves their relative scale free; canonical isometric normalization makes the Gram scalar.

The code and lattice routes do not repair this:

- a Golay rank-three invariant form appears only after choosing an ordered three-point flag, remains nonunique, and lives in characteristic three;
- the Leech lattice has no canonical rank-three summand;
- marked lattice planes can quantize an orientation already chosen but do not select it.

For the full connected group there is an exact representation-theoretic obstruction. Since

\[
\dim\mathfrak{sp}_4=10>9=\dim\mathfrak{gl}_3
\]

and (\mathfrak{sp}_4) is simple, every three-dimensional linear representation of (\mathfrak{sp}_4\cong\mathfrak{so}(2,3)) is trivial. The three-dimensional (H_2(\mathbb R)) carrier is a selected Jordan section or nonlinear conformal chart, not a three-dimensional linear module of the full (Spin_0(2,3)).

## 4. Combined theorem

Using only the structures already established in the corpus, and without importing (q_{QQ}), no canonical map

\[
Y:S_{\rm source}\to W_{\rm mediator}
\]

produces a protected non-scalar Gram with a uniquely oriented simple eigenspace.

The possibilities are exhaustive at this rung:

| construction | result |

## 6. Stop condition reached

The user-defined stopping rule was to continue each branch until no-go or indeterminate. That condition is now met for every internal route opened in waves 3 and 4:

- Furey-only derivation: scoped no-go with an explicit missing representation;
- action-only derivation: scoped no-go for parameter-independent orientation; conditional model prediction remains possible;
- topology/code/(Spin(2,3)) derivation: scoped no-go from established structures; indeterminate only after adding a new target action;

Continuing to add abstract carriers, anomaly-cancelling fields, loops, or direct-sum algebras without the named target action would add freedom rather than advance the selector question. The correct frontier is therefore pinned here until new mathematical or experimental data enter.
