# Open Letters

This programme turns mature corpus boundaries into narrow invitations for
expert criticism. It is correspondence infrastructure, not a scientific
branch and not evidence of endorsement.

## Current candidates

- [Cohl Furey](letter_to_cohl_furey.md): is the represented channel rotation
  intrinsic to the division-algebraic module or introduced by response
  packaging?
- [Lisa Randall](letter_to_lisa_randall.md): does the common
  \(Spin(2,4)\to Spin(2,3)\) ladder support a carrier-respecting comparison
  with Karch--Randall, or end at a source/representation mismatch?
- [Eric Weinstein](../../claims/1100-1199/1191_note_to_eric_weinstein_on_a_small_jordan_shiab_analogue.md):
  is the finite Peirce transport problem Shiab-like, or a
  Cartan/Gauss--Codazzi reduction with essential module-lift data?

The [letter manifest](letter_manifest.json) is the canonical collection index
for recipient, status, source and question. The Markdown documents contain the
letter content. Generated HTML is a reading projection only.

## Status rule

**Draft** means not sent. A status may change to **ready for review**,
**sent** or **response integrated** only after the corresponding real-world
event. AI answers, literature reviews and inferred reactions do not count as
replies from an addressee.

The earlier [open-letter answer programme](spin23_open_letter_answer_programme.md)
is a separate research packet built from standalone AI answers. It must not be
presented as expert correspondence.
