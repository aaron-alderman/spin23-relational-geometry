  Cartan/Gauss–Codazzi reduction with essential module-lift data?

The [letter manifest](letter_manifest.json) records recipient, status, source
and question. The Markdown letters are canonical; the website is generated
from them.

## Status rule

**Draft** means not sent. **Sent** and **response integrated** require the
corresponding real-world event.

The earlier [open-letter answer programme](spin23_open_letter_answer_programme.md)
is a separate research packet built from standalone AI answers. It must not be
presented as expert correspondence.
