## Reading the result

Each inherited cell is one object-to-topic claim family with exactly one disposition. If an object maps to several topics, those claims remain distinct: an operation can be established on one carrier and obstructed on another without contradiction. The multi-disposition count is therefore a join diagnostic, not an error. A title match is accepted as a strong route; a lead/context-only semantic route remains an explicit review queue. Unmapped scientific objects are not declared irrelevant merely because they lack frontier vocabulary. Typed exclusions remain in the inventory with their reason. The JSON register retains every object hash, source candidate and claim-family cluster.
