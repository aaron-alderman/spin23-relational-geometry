# Maintenance storage discipline

For repeated assembly, Claimipedia and isolated-bootstrap qualification, use `managed-validation/run.mjs` and read its README. Do not clone dated audit drivers to manufacture new full validation destinations. Historical dated evidence is frozen; improve the maintained runner instead.

Keep generated copies inside explicitly owned scratch space with cleanup on success and failure, bounded receipt retention and single-run admission. Do not automatically adopt or delete unmarked existing directories. Never follow a Windows junction during cleanup. Source repositories, source-history recovery archives, Context Hub state, runtime caches and research outputs require their own evidence and are outside validation retention.

If a new migration changes the selected source, update the managed qualification profile and its actual expectations explicitly. Do not weaken gates or silently call a stale profile current. Preserve the original user working changes.
