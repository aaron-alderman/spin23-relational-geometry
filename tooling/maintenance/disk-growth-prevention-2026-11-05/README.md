The runner owns one scratch directory under an exclusive lease. It releases assembly preparation, qualified consumers and each bootstrap in sequence. Child TEMP/TMP/TMPDIR also stay inside scratch, including compiler temporaries and interrupted test payloads. Success, failure, deadlines and handled cancellation reclaim scratch. An absent owner's partial workspace is recovered on the next run; a live tracked process prevents another allocation. Retention keeps two successful receipt sets and one failed set. The working budget is 4 GiB with a 2 GiB free-space reserve, sampled during execution; command logs are bounded to 8 MiB and each receipt set to 64 MiB. Existing pinned source bundles are reused rather than archived again.

Cleanup walks regular owned directories and unlinks junctions without following targets. Windows commands run inside a job assigned before their first instruction; closing the launcher terminates the assigned descendants. This replaced a separate `taskkill` operation that was denied by the restricted shell during testing.
