**Status:** active governed delivery plan  
**Endpoint:** a useful multi-agent attention instrument with exact receipts, human admission, rollback and identity-preserving federation; never an autonomous truth or corpus authority

## Delivery order

1. Stabilize retrieval identity and generated-surface ordering.
2. Seal the read-only search/context/beacon capability through Sourcery.
3. Exercise the direct inbox with external agent packets and human dispositions.
4. Run baseline-versus-adaptive episodes using independent task outcomes, not corpus-marker self-confirmation.
5. Admit the state-owning Observatory separately; never smuggle write authority through the read-only MCP.
6. Connect canonical corpus and publication first, then Claimipedia and Sourcery, and external literature last.
7. Measure longitudinal benefit, uncertainty, diversity, adverse evidence, rollback and capture resistance.

## Hard boundaries

- Attention utility is objective-scoped and is not truth probability.
- Inbox acceptance is acknowledgement, not admission to an attention state.
- An approved attention update cannot change source status or corpus content.
- One causal evidence family produces at most one effective update per source.
- No cross-objective transfer, reusable prior or shared learning is allowed without a separately qualified design.
- No lane may gain promotion authority by federation, popularity or graph centrality.
- Human purpose remains external to the estimator.

## Current architectural frontier

The local search implementation reads a live repository on Windows, while the protected Sourcery runtime is a separate Linux-hosted, algebra-first system that forbids opaque new executable callbacks. Sourcery exposes a mature exact-binding carrier. Its bounded-discovery successor also has a passing receipt and two proposals, but has not crossed into the integration head, a sealed runtime or an active tool catalogue. The local candidate now supplies the missing immutable transport inventory: each indexed path, byte count and hash, plus the aggregate corpus and evidence-projection identities. The manifest is not the payload and grants no authority. The remaining path is therefore explicit: integrate and seal the read boundary, transfer and re-hash every listed object, rebuild the same aggregate identity, then qualify the reflected ten-operation semantics. The older checkpoint, passing task, proposals, manifest and eventual payload each establish different coordinates; none can be relabelled as Context Hub admission.
