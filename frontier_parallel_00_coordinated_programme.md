## Coordination rules

1. Every thread emits a durable Markdown result even when the result is negative or indeterminate.
2. Exact calculations receive executable certificates where proportionate.
3. Isomorphic carriers do not count as physical intertwiners.
4. A free normalization, contact term, source choice or orientation remains visible in the claim.
5. A branch stays live when it produces a sharper calculation, constraint, model or falsifier. It is pinned when progress requires a named external datum. It closes only under a scoped no-go.
6. Cross-thread promotion requires a common action or an explicitly typed map; visual or dimensional resemblance is not enough.

## Claimipedia publication contract

Outputs enter Claimipedia first as proposal/review packets. Each item must include:

- claim text and status;
- exact scope and assumptions;
- evidence paths and executable receipts;
- dependencies and incompatible claims;
- direct falsifier or reopening criterion;
- authority boundary distinguishing theorem, verified model, candidate bridge and conjecture.

The admitted Scientific Derivation Composer may validate bounded typed paths and produce Triage handoffs. It does not itself grant truth or corpus admission. Final promotion therefore remains a separate Claimipedia review act.

## First cross-thread checkpoint

The seven routes meet at one question:

\[
\textit{Can one common action derive both the physical two-port source map and the topology/orientation selector?}
\]

If yes, the programme advances toward a distinctive \(Spin(2,3)\) theory. If no, the generic response theory and the Furey/exceptional topology remain mathematically valuable but physically separate.
