## Executive result

The missing state-to-Hessian law identified in document 1138 cannot be supplied by the Lagrangian/Jordan state alone while retaining full $Sp(4,\mathbb R)$ covariance.

Let

\[
\mathrm{Lag}(2,\mathbb R)
\cong Sp(4,\mathbb R)/P
\]

be the Lagrangian Grassmannian, locally coordinatized by $X\in H_2(\mathbb R)$. Suppose a putative adaptive law assigns a Hamiltonian generator

\[
\mathcal K(L)\in\mathfrak{sp}_4(\mathbb R)
\]

to each Lagrangian state and is fully covariant:

\[
\mathcal K(gL)=\operatorname{Ad}_g\mathcal K(L).
\]

Then

\[
\boxed{\mathcal K\equiv0.}
\]

Equivalently, under the standard identification $K=J\mathcal S$, there is no nonzero fully $Sp(4,\mathbb R)$-equivariant state-only assignment

\[
\mathcal S:\mathrm{Lag}(2,\mathbb R)
\longrightarrow \operatorname{Sym}_4(\mathbb R)
\]

with the corresponding congruence transformation law.

This changes the frontier. The absence of adaptive feedback in the corpus is not merely an unfinished formula. Under the strongest natural covariance requirement, such a formula cannot depend on one carrier state alone. A genuine return law must contain at least one additional datum: another state or face, a transported memory variable, external stress, a defect/reference frame, a connection or an explicitly symmetry-breaking metric.

That is a precise mathematical version of the relational-carrier principle:

\[
\boxed{
\text{one state can be transported, but it cannot covariantly prescribe its own nonzero transport.}
}
\]

## 1. Why equivariance reduces the problem to one stabilizer calculation

Choose the reference Lagrangian

\[
L_0=\{(q,0):q\in\mathbb R^2\}.
\]

Its stabilizer is the parabolic subgroup $P\subset Sp(4,\mathbb R)$. If $\mathcal K$ is equivariant and $h\in P$, then $hL_0=L_0$, so

\[
\mathcal K(L_0)
=\mathcal K(hL_0)
=\operatorname{Ad}_h\mathcal K(L_0).
\]

Therefore $\mathcal K(L_0)$ must be fixed by the adjoint action of the entire stabilizer. Conversely, any such fixed vector would generate an equivariant map on the homogeneous space. The problem is exactly the fixed subspace

\[
\mathfrak{sp}_4(\mathbb R)^P.
\]

## 2. The fixed subspace is zero

Write a general symplectic Lie-algebra element as

\[
K=
\begin{pmatrix}
U&Q\\
R&-U^T
\end{pmatrix},
\qquad Q=Q^T,
\quad R=R^T.
\]

The Lie algebra of the stabilizer of $L_0$ consists of

\[
H(A,B)=
\begin{pmatrix}
A&B\\
0&-A^T
\end{pmatrix},
\qquad B=B^T,
\]

with arbitrary $A\in M_2(\mathbb R)$.

First require

\[
[K,H(A,0)]=0
\]

for every $A$. The block equations imply

\[
[U,A]=0,
\qquad AQ+QA^T=0,
\qquad RA+A^TR=0
\]

for every $A$. Hence

\[
U=\alpha I_2,
\qquad Q=0,
\qquad R=0.
\]

Now commute this remaining candidate with the nilpotent part $H(0,B)$:

\[
\left[
\begin{pmatrix}
\alpha I&0\\0&-\alpha I
\end{pmatrix},
\begin{pmatrix}
0&B\\0&0
\end{pmatrix}
\right]
=
\begin{pmatrix}
0&2\alpha B\\0&0
\end{pmatrix}.
\]

Since this must vanish for every symmetric $B$, $\alpha=0$. Therefore

\[
\boxed{
\mathfrak{sp}_4(\mathbb R)^P=\{0\}.
}
\]

The executable certificate independently constructs all ten basis generators of $\mathfrak{sp}_4$, all seven generators of the stabilizer algebra and the full linear commutator system. Its constraint matrix has rank ten, leaving invariant-subspace dimension zero.

## 3. Why the obvious positive Hessian also fails

One may try to evade the abstract theorem by using the graph equation itself. After choosing the standard Euclidean splitting, define the positive-semidefinite penalty

\[
H_X(q,p)
=\frac12\lVert p-Xq\rVert^2.
\]

Its Hessian is

\[
\mathcal S_X
=
\begin{pmatrix}
X^2&-X\\
-X&I
\end{pmatrix}
=
\begin{pmatrix}-X\\I\end{pmatrix}
\begin{pmatrix}-X&I\end{pmatrix}
\succeq0.
\]

This construction already uses extra Euclidean structure and is not fully symplectic-covariant. More decisively, for the graph frame

\[
G_X=\begin{pmatrix}I\\X\end{pmatrix}
\]

one has

\[
\mathcal S_XG_X=0,
\qquad
J\mathcal S_XG_X=0.
\]

Thus the Hamiltonian flow generated by $J\mathcal S_X$ fixes every vector in the very graph from which it was built. The induced Riccati update is the identity on $X$.

This is a useful second no-go:

\[
\boxed{
\text{a quadratic residual that vanishes on the current carrier cannot move that carrier.}
}
\]

Positivity alone therefore does not create adaptation.

## 5. The minimum viable adaptive system is relational or extended-state

The forbidden form is

\[
X_{n+1}
=T_{\exp(\mathcal K(X_n))}(X_n)
\]

with $\mathcal K$ nonzero, state-only and fully $Sp(4)$-equivariant.

The live forms begin one rung higher:

\[
\mathcal K(X_n,Y_n),
\qquad
\mathcal K(X_n,M_n),
\qquad
\mathcal K(X_n;T_n),
\]

where $Y$ is a second face/reference Lagrangian, $M$ is transported memory or defect data, and $T$ is an external or composite stress/response field. A genuine adaptive return then has the schematic form

\[
\begin{aligned}
X_{n+1}&=T_{\exp(\mathcal K_\lambda(X_n,M_n))}(X_n),\\
M_{n+1}&=\Psi_\lambda(M_n,X_n).
\end{aligned}
\]

This is not yet a physical model. It is the minimum type signature that survives the theorem. The feedback variable must itself be transported or updated; otherwise it is only a fixed external parameter and document 1138's fixed-transport result returns.

The same point can be expressed in the programme's own language:

- **one carrier** supplies the state being transported;
- **two faces** supply a comparison, mismatch or orientation;
- **three relationships** can close a nontrivial update cycle;
- a lone face has no fully covariant direction in which to push itself.

Here “two” and “three” are structural prompts, not yet a derived dynamical law.

## 6. What this does and does not rule out

The theorem rules out only the conjunction of:

1. one Lagrangian/Jordan state as the entire input;
2. a generator valued in $\mathfrak{sp}_4$;
3. ordinary full $Sp(4,\mathbb R)$ equivariance;
4. a nonzero deterministic pointwise assignment.

It does **not** rule out:

- covariance under a physically selected subgroup;
- a second state, reference face or boundary condition;
- history dependence, delay or hysteresis;
- stochastic or distribution-valued updates;
- a connection whose holonomy depends on a traversed path rather than one point;
- stress, curvature, defect or response fields carrying independent information;
- dynamics on an enlarged state space followed by projection to $H_2$.

This is therefore a filter, not a closure of the generative-dynamics branch.
