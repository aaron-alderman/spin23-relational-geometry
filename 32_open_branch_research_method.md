# Open-Branch Research Method

**Purpose:** define the research grammar used across the Spin(2,3), Jordan, Furey, Standard Model, and stress–energy programmes  
**Status:** methodological control document  
**Core shift:** replace binary advocacy/refutation language with explicit branching, consequences, and stop-everything triggers

---

## 1. The phase shift

The programme should not be narrated primarily as a sequence of claims that are either “definitely true” or “not true.” That language is necessary at the level of a finished theorem or a falsified calculation, but it is too coarse for a research frontier.

The better question is:

> **Which paths remain open, what does each path commit us to, and what result would force us to stop and reorganise everything downstream?**

This produces a different posture:

- a comfortable path is not automatically preferred;
- an uncomfortable path is not automatically rejected;
- a negative result is not necessarily an endpoint;
- an exact result may open a more difficult branch rather than settle the theory;
- a “stop everything” result is valuable because it changes the shape of the tree.

The unit of research is therefore not an isolated claim. It is a **branch contract**.

---

## 2. The branch contract

Every live path should record seven things.

### 2.1 Premise

What are we provisionally allowing to be true?

Example:

> The exceptional Jordan algebra may be an internal selector geometry inside ordinary complex quantum field theory.

### 2.2 Attraction

Why is this path worth entering?

Example:

> It preserves the exact Standard Model stabilizer theorem while avoiding an immediate claim that exceptional quantum mechanics is fundamental.

### 2.3 Discomfort

What consequence makes the path difficult, costly, or conceptually unwelcome?

Example:

> If the nested pair is dynamical, the (F_4/G_{SM}) directions may generate forty additional modes whose physical fate must be explained.

The discomfort must be stated before it is softened. This prevents the programme from unconsciously choosing assumptions only because they preserve the preferred story.

### 2.4 Next discriminant

What is the smallest calculation that separates this branch from its siblings?

Example:

> Decompose the tangent representation of the nested-pair orbit under (G_{SM}) and calculate the quadratic spectrum of the smallest selector action.

### 2.5 Stop-everything trigger

What result would require pausing all dependent work?

Example:

> If a physical ghost survives every available gauge or constraint reduction, stop building phenomenology on that selector action.

A stop-everything trigger does not always kill the whole programme. It identifies the exact subtree whose downstream work becomes invalid.

### 2.6 Consequence if true

Complete the sentence:

> **If this is true, then...**

This is where the real value of the branch appears. A result is strategically important when its truth changes what must be done next.

### 2.7 Re-entry conditions

If the branch is paused, what new theorem, mechanism, or evidence would justify reopening it?

This prevents both premature burial and endless resurrection without new information.

---

## 3. Branch statuses

The following statuses describe a research tree better than a simple true/false ledger.

| Status | Meaning |
|---|---|
| `OPEN` | coherent path with an identified next discriminant |
| `OPEN–UNCOMFORTABLE` | coherent path whose implications are severe but must be investigated |
| `PRESSURE-TEST` | path retained mainly because it can expose hidden assumptions in the preferred branch |
| `DEPENDENT` | cannot be evaluated until an upstream result is available |
| `STOP-TRIGGERED` | a decisive result invalidated downstream work on this branch |
| `DORMANT` | no current discriminant is worth the cost, but re-entry conditions are recorded |
| `MERGED` | an explicit equivalence or intertwiner joined previously distinct branches |
| `SPLIT` | a supposed single path was shown to contain inequivalent constructions |
| `RE-ROOT` | the result changes the programme's starting ontology or central object |

These statuses complement—not replace—claim labels such as `STANDARD`, `EXACT-LOCAL`, `CONDITIONAL`, and `NO-GO`. Claim status describes epistemic authority. Branch status describes what the programme should do.

---

## 4. What “stop everything” means

“Stop everything” is not dramatic language for ordinary disappointment. It is a controlled response to a result that invalidates shared downstream assumptions.

There are four levels.

### Level 1 — stop a calculation

A convention, implementation, or ansatz fails. Repair it before interpreting the output.

### Level 2 — stop a model

A particular action has ghosts, wrong anomalies, or an inconsistent state count. Other actions in the same broad programme remain open.

### Level 3 — stop a branch

A whole ontology or carrier class conflicts with a theorem or unavoidable physical requirement. Dependent papers and phenomenology pause.

### Level 4 — re-root the programme

A result changes the most economical starting point.

Examples include:

- the natural Jordan flag carrier exactly reproduces the chiral Standard Model and its invariant tensors;
- the exceptional composition obstruction is proved unavoidable for every intended physical reading;
- a precise intertwiner shows that the Furey and exceptional-Jordan constructions are the same internal mechanism;
- the common Jordan–Spin(2,3) action has an unavoidable ghost or anomaly;
- complexification is proved necessary for chirality or proved physically redundant.

At Level 4, the correct response is not to patch prose. It is to redraw the research tree.

## 5. Current Jordan frontier as an open tree

### Branch J0 — what is the exceptional Jordan algebra physically?

#### J0-A: fundamental observable algebra

**Status:** `OPEN–UNCOMFORTABLE`

**Premise:** (\mathfrak h_3(\mathbb O)) is literally part of the fundamental algebra of quantum observables.

**Attraction:** takes the observable interpretation seriously and may explain gauge symmetry from measurement structure.

**Discomfort:** standard Euclidean-Jordan composition results obstruct coupling an exceptional system to ordinary nonclassical systems.

**Next discriminant:** specify a concrete composition rule or host category and test non-signalling, positivity, locality, and recovery of ordinary tensor-product quantum theory.

**Stop-everything trigger:** prove that every composition rule compatible with the programme's required physical principles excludes an exceptional factor.

**If true:** ordinary QFT is emergent or incomplete at the compositional level; the programme must become a theory of nonstandard quantum composition.

**Re-entry condition after failure:** a new composition theorem or explicit host theory evading a named assumption.

#### J0-B: internal selector geometry

**Status:** `OPEN`

**Premise:** the Jordan algebra organises internal symmetry selection inside conventional complex QFT.

**Attraction:** retains the stabilizer theorem and ordinary locality/composition.

**Discomfort:** the algebra may explain only the gauge group and not the matter content; the deeper “observables” interpretation becomes weaker.

**Next discriminant:** construct the nested-pair selector and its matter representation in an ordinary complex field theory.

**Stop-everything trigger:** show that every healthy host construction erases the exceptional structure or leaves all low-energy coefficients arbitrary.

**If true:** the Jordan programme becomes an internal order-parameter theory rather than a replacement for quantum mechanics.

#### J0-C: pre-geometric or emergent composition

**Status:** `PRESSURE-TEST`

**Premise:** the exceptional algebra applies before spacetime factorisation; ordinary local composition emerges only after selection.

**Attraction:** could connect observable selection with the wider admissibility and spacetime-selection programme.

**Discomfort:** emergence of locality, tensor products, and relativistic causality becomes an enormous additional burden.

**Next discriminant:** construct even one finite multi-site model whose reduced sector has an ordinary tensor-product Hilbert space.

**Stop-everything trigger:** demonstrate that the proposed reduction cannot generate independent subsystems or local tomography in the observed regime.

**If true:** the composition obstruction becomes a clue about why spacetime and subsystem factorisation emerge together.

### Branch J1 — what does the nested flag determine?

#### J1-A: gauge group only

**Status:** `OPEN`

**Premise:** the nested qubit–qutrit flag explains the faithful Standard Model gauge group but not matter.

**Attraction:** this is already a clean and meaningful structural result.

**Discomfort:** the construction may stop just before the physically distinctive content—chirality, generations, Higgs, and flavour.

**Next discriminant:** calculate the full (G_{SM}) branching of the Jordan algebra, flag tangent space, and nearby natural representations.

**Stop-everything trigger:** none for the theorem itself; instead, stop claiming a complete Standard Model if no natural matter carrier appears.

**If true:** the Jordan theorem becomes the internal-symmetry foundation upon which a separate matter mechanism must be placed.

#### J1-B: flag tangent directions contain physical matter or Higgs structure

**Status:** `OPEN–UNCOMFORTABLE`

**Premise:** the broken or transverse directions around the nested pair carry physically relevant Standard Model representations.

**Attraction:** could join gauge selection and particle content in one geometry.

**Discomfort:** the coset has forty directions; it may produce unwanted states, mirrors, or a large exotic sector.

**Next discriminant:** exact branching, chirality assignment, spin-statistics interpretation, and anomaly audit.

**Stop-everything trigger:** the natural branching exactly matches a full chiral generation or Higgs/Yukawa system with no arbitrary projection.

**If true:** pause the broader matter-carrier search and re-root the internal programme around the flag geometry.

The trigger is positive because a sufficiently strong success can be as programme-changing as a no-go theorem.

#### J1-C: the flag requires a separate Furey-style ideal module

**Status:** `OPEN`

**Premise:** Jordan geometry selects the group while division-algebraic ideals supply the fermions.

**Attraction:** assigns each formalism the task it performs most naturally.

**Discomfort:** risks becoming a stitched architecture with independent choices rather than one explanation.

**Next discriminant:** construct the (G_{SM})-equivariant coupling and test whether the Jordan flag uniquely selects the Furey projector or merely tolerates it.

**Stop-everything trigger:** find an explicit canonical intertwiner between the flag data and the ideal projector.

**If true:** merge the Furey and Jordan branches into one internal-selection programme.

---

### Branch J2 — real or complexified Jordan algebra?

#### J2-A: real (\mathfrak h_3(\mathbb O)) is sufficient

**Status:** `OPEN`

**Attraction:** exact gauge-group theorem, Euclidean order structure, fewer choices.

**Discomfort:** complex chirality and physical fermion carriers may still need an external complex host.

**Next discriminant:** complete the matter and invariant audit in the real-algebra-plus-complex-host architecture.

**Stop-everything trigger:** demonstrate that a required chiral or Yukawa structure cannot exist without intrinsic complexification.

**If true:** demote (J_3(\mathbb C\otimes\mathbb O)) from fundamental arena to optional computational extension.

#### J2-B: complexification is physically necessary

**Status:** `OPEN–UNCOMFORTABLE`

**Attraction:** may provide chirality, phases, or a more direct matter carrier.

**Discomfort:** loses the immediate Euclidean-observable interpretation, enlarges admissibility freedom, and risks reverse-engineering the answer.

**Next discriminant:** identify one physical structure available only in the complexified branch and prove it survives reduction.

**Stop-everything trigger:** a unique anomaly-free chiral module or indispensable invariant exists only after complexification.

**If true:** re-root the Jordan programme around a controlled reality condition rather than the real algebra alone.

---

### Branch J3 — fixed or dynamical nested pair?

#### J3-A: fixed background flag

**Status:** `OPEN`

**Attraction:** simplest way to use the theorem.

**Discomfort:** does not explain why this flag is selected and may hide explicit symmetry breaking.

**Next discriminant:** quantify radiative stability and whether physical predictions depend on flag orientation.

**Stop-everything trigger:** demonstrate observable orientation dependence not removed by (F_4) equivalence.

#### J3-B: global flag sigma model

**Status:** `OPEN–UNCOMFORTABLE`

**Attraction:** selection becomes dynamical.

**Discomfort:** potentially forty Goldstone-like modes.

**Next discriminant:** invariant-potential and quadratic-spectrum calculation.

**Stop-everything trigger:** unavoidable massless modes conflict with observation.

**If true and healthy:** the internal selector has a calculable stress tensor and portal sector.

#### J3-C: gauged (F_4\to G_{SM})

**Status:** `OPEN–UNCOMFORTABLE`

**Attraction:** broken directions can be eaten by massive gauge bosons.

**Discomfort:** introduces forty heavy gauge directions and potentially severe phenomenological and anomaly burdens.

**Next discriminant:** coset branching, mass spectrum, fermion couplings, and EFT matching.

**Stop-everything trigger:** any unavoidable gauge anomaly, physical ghost, or experimentally excluded operator tied to the required breaking scale.

**If true and healthy:** the programme becomes a concrete exceptional gauge theory rather than only a stabilizer interpretation.

#### J3-D: constrained auxiliary selector

**Status:** `PRESSURE-TEST`

**Attraction:** avoids a large propagating sector.

**Discomfort:** may merely hide the selection problem in a constraint.

**Next discriminant:** derive the constraint from a symmetry or controlled limit.

**Stop-everything trigger:** no radiatively stable or variational origin for the constraint exists.

### Branch J4 — relationship to Spin(2,3)

#### J4-A: factorised external and internal selectors

**Status:** `OPEN`

\[
Spin(2,3)\to Spin(1,3),
\qquad
F_4\to G_{SM}.
\]

**Attraction:** cleanly separates spacetime and internal tasks while allowing coupling through one action.

**Discomfort:** may feel less “unified” and introduces two selection mechanisms.

**Next discriminant:** classify portals and ask whether one coefficient controls both internal selection and stress response.

**Stop-everything trigger:** an unavoidable incompatibility prevents one Dirac operator from preserving both selected sectors.

**If true:** the programme has a conservative common architecture ready for spectrum and EFT analysis.

#### J4-B: one deeper algebraic selector

**Status:** `OPEN–UNCOMFORTABLE`

**Premise:** Jordan and Spin(2,3) selections are two faces of one deeper structure.

**Attraction:** stronger unification and potentially fewer arbitrary selectors.

**Discomfort:** high risk of dimension matching, mixed category errors, and oversized parent groups.

**Next discriminant:** produce an explicit functor, representation, or action that yields both stabilizers without selective inserts.

**Stop-everything trigger:** a minimal common parent with a healthy physical module and fewer parameters than the factorised theory is constructed.

**If true:** pause the factorised model and re-root around the common selector.

### Branch J5 — integral octonions and the Leech lattice

#### J5-A: arithmetic Jordan selector

**Status:** `OPEN–UNCOMFORTABLE`

**Premise:** an integral form of the exceptional Jordan algebra and its Leech-lattice relation discretise the family of admissible nested Standard Model flags.

**Attraction:** may replace an arbitrary selector potential with arithmetic admissibility.

**Discomfort:** exact lattice preservation leaves discrete rather than continuous symmetry and may destroy the local Standard Model gauge group.

**Next discriminant:** embed Wilson's octonionic Leech lattice in the off-diagonal (\mathbb O^3) sector, test Jordan-product/cubic-norm integrality, and classify integral-compatible nested flags.

**Stop-everything trigger:** one natural arithmetic orbit uniquely extends to the Baez–Schwahn flag and recovers the continuous stabilizer after real extension.

**If true:** pause arbitrary dynamical flag potentials and re-root selection around the integral exceptional-Jordan structure.

**Reverse trigger:** if compatibility is only the vector-space coincidence (\mathbb O^3\cong\mathbb R^{24}), keep the Leech construction as a neighbouring mathematical branch rather than a physical selector.

## 6. How to choose what to calculate next

Do not choose only the most likely branch. Choose a portfolio containing:

1. one strong baseline;
2. one uncomfortable branch with high consequence;
3. one pressure-test branch that could expose a hidden assumption;
4. one discriminant shared by several branches.

For the current Jordan programme:

| Role | Branch | Immediate calculation |
|---|---|---|
| Strong baseline | J0-B internal selector | explicit host and nested-pair stabilizer implementation |
| Uncomfortable branch | J0-A fundamental observable algebra | composition-rule audit |
| Pressure test | J2-B complexification necessary | search for uniquely complex chiral/invariant structure |
| Shared discriminant | J1 flag content | full (G_{SM}) branching and anomaly table |

This portfolio deliberately includes work that might destabilise the preferred architecture.

## 7. Reporting format

Every research-round conclusion should use this template:

```text
Branch:
Status:
Premise:
What became sharper:
What became more uncomfortable:
Next discriminant:
Stop-everything trigger:
If true, then:
If false, then:
Dependencies affected:
Re-entry condition:
```

Avoid ending with only “supported,” “not supported,” or “more work is needed.” State how the tree changed.

## 8. Relationship to falsification

This method does not weaken falsification. It makes falsification more precise.

A model can still be false. A theorem can still exclude a class. An anomaly can still terminate a carrier. The difference is that the programme records **which dependencies die with it** and **which adjacent paths become more important**.

For example:

- an anomalous Todorov carrier stops that carrier, not the Baez–Schwahn stabilizer theorem;
- a ghost in one flag potential stops that action, not every dynamical flag model;
- a general coset no-go stops the dynamical-selector branch and strengthens the fixed/auxiliary branches;
- proof that real (J) cannot support the needed chiral invariant strengthens the complexified branch;
- proof of a canonical Jordan–Furey intertwiner merges two branches and changes the programme root.

The purpose is neither optimism nor pessimism. It is dependency-aware inference.

---

## 9. Final principle

The programme should repeatedly ask:

> What are we currently allowing to be possible, what is uncomfortable about allowing it, and what result would make us stop everything downstream because the world would have to be different from the one we were modelling?

That question keeps the frontier open without making it vague. It gives uncomfortable paths genuine protection from premature dismissal, while giving decisive results enough authority to reorganise the entire project.

The desired research culture is:

> **branch widely, calculate discriminants, record dependencies, and welcome the result that forces the tree to be redrawn.**
