# D-02 bounded exhaustion audit

## Final semantic object

The correct global object is not always one matrix at the rank-changing point. It is a response functor on approach arcs:

`gamma -> lim (A - B D^-1 B^T) along gamma`,

where an output may be a finite value, a pole class, or a refusal receipt. Analytic invertible interior-frame changes and regular parameter changes are morphisms. A single response descends to the singular point exactly when this functor has one finite value on every admitted approach arc.

This supplies the promised groupoid gluing without pretending that all groupoid-valued families descend. A positive operator-valued Herglotz measure can represent each passive branch, but positivity does not identify branches with different residues.

## Strongest bounded counterexample

Fix any finite retained jet order `N` and put `k=N+1`. Consider

`D(x,y)=x^(2k) z`, `B(x,y)=y`.

The paths `(x,y)=(t,0)` and `(t,c t^k)` have the same `N`-jet and the same tangent direction. Their Schur corrections tend to `0` and `c^2/z`. Thus no fixed finite collection of tangent/jet decorations resolves arbitrary contact order. Iterated normal blow-ups can resolve any declared bounded-order instance, but there is no uniform finite decoration for the unbounded class.

There is an even harder category boundary. In the smooth category,

`D_s=e^(-2/s^2) z`, `B_s=c e^(-1/s^2)`

has every Taylor coefficient zero at the origin while the correction is identically `c^2/z` off it. Even the infinite Taylor jet loses the quotient data. The analytic hypothesis is therefore doing real work.

## Exhausted dispatcher

- Constant support: apply the local support-Schur theorem.
- Rank change with one finite cluster value of the full correction: remove the singularity and glue.
- Multiple finite cluster values: retain the approach-arc groupoid; no single value descends.
- Any unbounded admitted approach: retain the interior or refuse elimination.
- Explicit normal coordinate plus subtraction prescription: a scheme-relative renormalized value is allowed, with the scheme retained in its type.

Ward, common-temperature KMS and probe-visible wall residue remain conditional decorations. Bulk index and oriented/grading holonomy remain separate data.

## Why this is bounded exhaustion

Within finite-dimensional analytic or polynomial germs, every rank-changing case lands in exactly one of the finite-singleton, finite-nonsingleton, or unbounded cluster classes. Better singularity-resolution algorithms may make the arc labels more economical, but cannot create a fourth disposition.

The following are explicitly new programmes rather than open cases inside D-02: smooth full-germ calculi, Fredholm/essential-spectrum operator extensions, interacting gauge-wall existence, and nonequilibrium matrix fluctuation relations.
