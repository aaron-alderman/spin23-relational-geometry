# ⌖ Cartographer

_Research-move page_

maps territory, distinctions, dependencies and interfaces. This describes the work performed by a passage, not a personality type.

## How to read it

Treat this mark as a verb. It names the work the passage is doing and therefore the kind of question a reader should ask of it.
