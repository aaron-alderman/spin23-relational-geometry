# ⊕ Integrator

_Research-move page_

joins several typed results while letting the weakest edge set the claim. This describes the work performed by a passage, not a personality type.

## How to read it

Treat this mark as a verb. It names the work the passage is doing and therefore the kind of question a reader should ask of it.
