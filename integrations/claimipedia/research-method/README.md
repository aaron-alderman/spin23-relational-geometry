# Claimipedia option-preserving research method

This directory turns four existing research practices into one reusable meta² process:

1. `32_open_branch_research_method.md` supplies branch contracts, discriminants, stop triggers and re-entry conditions.
2. Claimipedia's pyramids research model supplies the lightning-strike rule: conditionally assume the terminal proposition, enumerate every necessary link, and require each link to close independently.
3. The programme continuation maps keep landscape value separate from closure value.
4. The admitted Sourcery scientific-derivation composer searches typed, evidence-bound transformation paths without granting them truth or admission authority.

The process is **meta²** because the research method is itself represented as a typed, reviewable process. Its phases, option points, layer boundaries, symmetry census, decisions and receipts are data rather than hidden prompt procedure.

## Apply it to another question

Create an instance with:

- one bounded terminal proposition;
- a separate ledger entry for every required layer;
- a closed-world symmetry census for the declared scope, plus an explicit frontier for anything not yet classified;
- at least two retained alternatives at every genuine choice point;
- explicit bridges whenever an inference crosses layers;
- a continuous lightning-strike chain whose links each have a closure test and a falsifier;
- separate landscape and closure outputs;
- proposal-only authority unless a later governed process supplies stronger authority.

Then run:

node .\compile-research-strike.mjs

node .\run-d02-sourcery-review.mjs
