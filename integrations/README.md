# Integrations

This directory contains application-specific research packets and publication workflows.

- `claimipedia/` contains the publication-authority contract, campaigns, research-method material, manifests and the orientation pilot;
- `sourcery/` contains Sourcery admission and scientific-derivation material.

The [corpus search MCP candidate](../tooling/search/MCP.md) exposes hybrid lexical/PageRank retrieval, tailored and swept context, answer receipts, stability comparison, caller-owned [receipt-driven belief updates](../tooling/search/BELIEF_LOOP.md), bounded adaptive context and source reading for an LLM interface. Its [sealed-source candidate manifest](../tooling/search/sourcery_admission_candidate_v1.json) is locally qualified and read-only; protected-runtime admission remains a separate governed step.

Integration receipts record application state. They do not supersede the canonical claim ledger or its epistemic labels.
