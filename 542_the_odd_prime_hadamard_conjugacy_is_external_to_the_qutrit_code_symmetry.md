# The odd-prime Hadamard conjugacy is external to the qutrit code symmetry

## Status

**Exact comparison of the exhaustive qutrit code automorphism image with the odd-prime Heisenberg/Weil group.**

The odd-prime equivalence between puncture exchange and \(D_2\) root exchange is mathematically real, but it is not implemented by the twice-punctured qutrit code symmetry. Even after adjoining the source-derived mutual \(K_+\) phase, the missing root exchange is not generated.

This pins a potential overinterpretation of the preceding result:

\[
\boxed{
\text{Clifford conjugacy on the ambient Heisenberg carrier}
\ne
\text{symmetry of the source code}.}
\]

## 1. Converting the source action to the \(D_2\) basis

The exhaustive code calculation found puncture-coordinate actions

\[
\mathcal G_{\rm punct}
=\{\pm I,\pm P\},
\qquad
P=\begin{pmatrix}0&1\\1&0\end{pmatrix}.
\]

The root-to-puncture basis matrix is

\[
H=\begin{pmatrix}1&1\\1&-1\end{pmatrix}.
\]

At \(p=3\), it is invertible and

\[
H^{-1}PH
=A
=\begin{pmatrix}1&0\\0&-1\end{pmatrix}.
\]

Therefore the actual code image in the \(D_2\) root basis is

\[
\boxed{
\mathcal G_{\rm root}
=\{\pm I,\pm A\}.}
\]

It contains neither

\[
R=\begin{pmatrix}0&1\\1&0\end{pmatrix}
\]

nor the conjugating matrix \(H\).

The notation matters: \(P\) is puncture exchange in the puncture basis, while \(R\) is root exchange in the root basis. Giving both the same displayed swap matrix without recording the basis would incorrectly identify two different operations.

## 2. The mutual phase does not generate the missing exchange

The qutrit \(K_+\) phase has symplectic shear

\[
L_K=
\begin{pmatrix}
I&0\\
K&I
\end{pmatrix},
\qquad
K=\begin{pmatrix}0&2\\2&0\end{pmatrix}.
\]

The source puncture action in the root basis lifts as

\[
\widehat A=\operatorname{diag}(A,A^{-T}).
\]

It reverses the shear:

\[
AKA=-K,
\qquad
\widehat A L_K\widehat A^{-1}=L_K^{-1}.
\]

Consequently,

\[
\langle\widehat A,L_K\rangle\cong S_3
\]

has order six. Adding the global central sign gives

\[
\boxed{
\langle\widehat A,L_K,-I\rangle
\cong S_3\times C_2,
\qquad
|\langle\widehat A,L_K,-I\rangle|=12.}
\]

Every element has \(X\)-block in

\[
\{\pm I,\pm A\}.
\]

Neither the root lift \(\widehat R\) nor the Hadamard lift \(\widehat H\) belongs to this group.

Thus the mutual phase enriches the code's logical Clifford image but cannot manufacture the missing change of \(X\)-basis.

## 3. What the odd-prime conjugacy really says

On the ambient Heisenberg group,

\[
\widehat H^{-1}\widehat A\widehat H=\widehat R.
\]

This says the two involutions define equivalent presentations after an allowed ambient Clifford basis change. It does **not** say that \(\widehat H\) preserves the fourteen-column code configuration, nor that it is generated by the source transversals and monomial automorphisms.

The hierarchy is:

\[
\boxed{
\text{source code group}
\subsetneq
\text{source-generated logical Clifford subgroup}
\subsetneq
\text{ambient Clifford group}.}
\]

Root exchange appears only at the last level with the currently known generators.

## 4. Consequences

### Established

- the code's order-24 projective group reduces to four actions on the deleted pair;
- in the \(D_2\) root basis those are \(\{\pm I,\pm A\}\);
- \(R\) and \(H\) are absent;
- adjoining the mutual \(K_+\) phase produces an order-12 subgroup \(S_3\times C_2\);
- root exchange remains absent from that enlarged source-generated subgroup.

### Interpretation

The qutrit theory removes the algebraic conjugacy obstruction but not the source-selection obstruction. This is an important distinction:

- at \(p=2\), \(A\) and \(R\) are not even ambiently conjugate on the same logical module;
- at \(p=3\), they are ambiently conjugate, but the needed conjugator is not a known code symmetry.

The prime-three result therefore opens a possible extension rather than completing the identification.

## 6. Stop-everything and falsification gates

### Stop-everything

1. A canonical code deformation realizes \(\widehat H\) and intertwines the two source presentations.
2. The doubled Dirac carrier contains both \(\widehat A\) and \(\widehat R\), with \(\widehat H\) fixed by chirality or charge flow.
3. The two adjacent \(Spin(2,3)\) fibers admit \(H\) as their unique arithmetic transition function.

### Boundaries

- ambient Clifford equivalence is not source symmetry;
- the mutual qutrit phase alone cannot create root exchange;
- equal group orders or conjugate abstract actions do not provide a field-labelled intertwiner;
- any future claim must state the basis in which each swap matrix is written.
